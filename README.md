# Operating Systems Simulator – Second Year Assignment

This repository contains four C-based educational software models:
1. Windows 11
2. macOS
3. ChromeOS
4. Linux

The assignment demonstrates how operating-system concepts can be represented in a working program rather than attempting to build a complete operating system from scratch.

## Concepts
- Process management
- CPU scheduling: FCFS and Round-Robin
- Memory management
- File management
- File permissions
- User mode and kernel mode

## Repository structure
```text
Windows-OS/
macOS/
ChromeOS/
Linux/
Assignment-Report/
```

## Important
These programs are **simulators/models**, not the actual Windows, macOS, ChromeOS or Linux kernels.
